# Cleaned up Mehville RC 6744 Reefscape Development 2025
- Updated 27Jan2026

### Purpose
This project is an update of the original project archived at: https://github.com/MHS-Pi-6744/6744-Reefscape-Development.git

That original project has been cleaned up and extra documentation has been added to make this a useful reference for student robot coders. The goal is to make it easier to learn how to develop a robot programmed in Java for FRC competition. 

It has not been tested on the robot, so it is more of a guideline for new robot development. 

If the documentation and organization style is helpful then please adapt it to new projects.

There are two documents in /docs. 
- ForNewProgrammers.md -- a overview to read first.

- PathPlanner.md -- a description of how PathPlanner works, since so much of it is hidden behind the scenes.


This project was developed with help from ChatGPT.
